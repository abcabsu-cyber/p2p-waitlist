# Анкеты → Google Таблица → бот BotHelp

## Установка / обновление скрипта

1. Таблица → **Расширения → Apps Script**. Замените весь `Code.gs` содержимым файла `Code.gs` из этой папки. Сохраните.
2. Выберите функцию `setup` → **Выполнить**. Появятся листы «Заявки» и «Визиты» (в «Заявках» добавится колонка `cuid`).
3. Первый раз: **Начать развёртывание → Новое развёртывание → Веб-приложение**, запуск от имени «Я», доступ «Все». Адрес `…/exec` вставить в `SCRIPT_URL` в `index.html`.
   После изменений кода: **Начать развёртывание → Управление развёртываниями → ✏️ → Версия: Новая версия → Развернуть**. Адрес не меняется.

## Ссылка на сайт в боте

```
https://ibnyusupow.ru/?tg_id={%user_id%}&cuid={%cuid%}&video=КЛЮЧЕВОЕ_СЛОВО
```

`{%user_id%}` и `{%cuid%}` BotHelp сам подставит для каждого человека (вставляются кнопкой `<>`).
`video` — ключевое слово материала, чтобы в таблице было видно, после какого рилса пришла анкета.

## Как бот узнаёт статус человека

Скрипт отвечает на запрос `GET <адрес …/exec>?tg_id=123`:

```json
{"ok":true,"tg_id":"123","status":"filled","filled":true}
```

| status    | значит                                   |
|-----------|-------------------------------------------|
| `filled`  | анкета заполнена                          |
| `visited` | открыл сайт из бота, анкету не отправил   |
| `none`    | на сайт не переходил                      |

## Настройка в BotHelp

Заведите пользовательское поле подписчика `anketa_status`.

Перед каждым дожимом добавьте шаг с действием **«Внешний запрос»**:
- Метод: **GET**
- URL: `<адрес …/exec>?tg_id={%user_id%}`
- Сохранение ответа: JSON Path `$.status` → поле `anketa_status`
- Кнопкой «Тестовый запрос» проверьте, что приходит `200 OK` и значение `none`

Затем шаг **«Условие»**: `anketa_status` = `filled`
- **Да** → сообщение со ссылкой на канал + тег (например, `анкета`) → конец цепочки дожима
- **Нет** → дожимающее сообщение → задержка → снова «Внешний запрос» + «Условие»

Схема цепочки:

```
Выдача материала → задержка 10 мин → ссылка на анкету
  → 30 мин → [запрос + условие] → filled? да: канал | нет: письмо 1
  → 60 мин → [запрос + условие] → filled? да: канал | нет: письмо 2
  → след. день → [запрос + условие] → filled? да: канал | нет: письмо 3
  → [запрос + условие] → нет: в общую рассылку
```

Статус `visited` можно использовать для другого текста письма: «Ты открыл анкету, но не дописал».
