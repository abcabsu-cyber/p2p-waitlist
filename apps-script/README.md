# Анкеты → Google Таблица

## Установка (5 минут)

1. Создайте Google Таблицу (например «Предзапись P2P»).
2. В таблице: **Расширения → Apps Script**. Удалите всё в `Code.gs` и вставьте содержимое файла `Code.gs` из этой папки. Сохраните.
3. Вверху выберите функцию `setup` → **Выполнить**. Разрешите доступ к таблице. Появится лист «Заявки» с шапкой.
4. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение»:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
5. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
6. В `index.html` вставьте его в строку `const SCRIPT_URL = "";` и запушьте. Надпись «Демо-режим» пропадёт.

> После правок в `Code.gs` нужно **Развёртывания → Управление → изменить → Новая версия**, иначе работает старый код. Адрес при этом не меняется.

## Ссылка из бота

Бот даёт ссылку на сайт с id пользователя и меткой ролика:

```
https://<сайт>/?tg_id={id пользователя}&video={метка рилса}
```

`tg_id` и `video` попадают в таблицу вместе с анкетой.

## Как бот узнаёт, что анкета заполнена

**Проверка перед дожимом (работает с любым конструктором и своим кодом).**
Перед каждым напоминанием бот делает GET-запрос:

```
https://script.google.com/macros/s/…/exec?tg_id=123456789
```

Ответ: `{"ok":true,"tg_id":"123456789","filled":true}`. Если `filled` = `true`, напоминание не отправляем и выходим из цепочки.

**Сигнал сразу после отправки (необязательно).**
Если у бота есть входящий вебхук, впишите его адрес в `BOT_WEBHOOK_URL` в `Code.gs`. Скрипт пришлёт POST с JSON:

```json
{"event":"form_submitted","tg_id":"123456789","video":"reels_05","telegram":"@nick","name":"…","readiness":"7"}
```
